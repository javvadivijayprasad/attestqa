Fixes from the first end-to-end runs of 2.3.0. (1) A write to an epic's shared feature file can no longer remove another story's scenarios when the run has not read the file: the rule compared the write with what the run had seen, and a run that wrote without reading overwrote four scenarios of another story; it now reads the file in the workspace. With no workspace, as when a ledger is replayed alone, nothing changes. (2) `synthdata.examples` refuses a rule on the length of a text column, because synthdata 1.4.0 ignores it and returned a one-character value as valid for a field of 11 to 21 characters; the agent is told to work those boundaries out itself, and number ranges, allowed sets and required fields are unaffected. (3) The run report no longer says "Suite: green" for a story none of whose design items has a test; it says no test of that story ran and that the tests which did run belong to other stories. (4) A URL refused for being out of scope now names the allowed URLs and says that another host name or port is refused the same way; told only "not allowed", an agent that had picked up a stale port tried three other host names before stopping. (5) The skill now says a message's exact wording is asserted only when the story or a named source quotes it; otherwise the test asserts only what the story says the message tells the user. A run had invented a message's wording and failed five tests on it. Also: two stories that state their limits were added to the Booker and Toolshop evaluation backlogs, for testing generated values end to end.
