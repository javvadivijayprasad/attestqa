Jira adapter (`jira.*` tools): read an issue (summary, type, status, description, acceptance criteria from a configured field or a description section, labels, links, sub-tasks), read its comments, and run a JQL search; create a Bug linked to its story after approval. Works with Jira Cloud (API v3, email + API token) and Data Center (API v2, personal access token). There is no tool to edit, transition, comment on or delete anything.
