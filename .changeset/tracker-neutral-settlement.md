The end-of-run bug settlement and the approval prompt now read a proposed bug through the same tracker-neutral description the refusal rules use, so the three judge and show one bug. Before, each took the title, the story link, the tags and the steps out of the call its own way, after a Jira bug had been dressed up as an Azure DevOps one; that conversion is removed. Nothing a run or a reviewer sees changes: the 86 bugs proposed across the recorded runs were settled and rendered before and after, and the output is the same character for character. One edge is deliberately different: a bug proposed with an empty title is shown as "(untitled)" where it used to be shown as nothing.
