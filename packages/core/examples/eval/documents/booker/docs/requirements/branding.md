# Branding — the B&B's own details

In Branding the owner sets what the guest website says about the B&B: its name, its description
and its contact details.

Limits and message wording confirmed against the local application on 17 Nov 2026.

## B&B name

The B&B name must be 3 to 100 characters long.

When it is empty the change is not saved, the guest site keeps the old name, and this message is
shown:

> Name should not be blank

When it is shorter or longer than allowed, this message is shown:

> size must be between 3 and 100

## B&B description

The description must be 3 to 500 characters long.

When it is empty the change is not saved and this message is shown:

> Description should not be blank

When it is shorter or longer than allowed, this message is shown:

> size must be between 3 and 500

## Contact name

The contact name shown to guests must be 3 to 40 characters long.

When it is empty the change is not saved and this message is shown:

> Contact Name should not be blank

When it is shorter or longer than allowed, this message is shown:

> size must be between 3 and 40
