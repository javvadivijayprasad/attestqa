# research

The record that turns development into evidence. Plan: `Docs/08_Research_Logging_Plan.pdf`.

| File | What goes in it |
|---|---|
| `findings.jsonl` | One line per finding, always pointing at ledger events |
| `decisions/ADR-NNN-*.md` | Why the design is the way it is |
| `hypotheses.md` | Written and hashed before a study collects data |
| `runs-manifest.csv` | One row per counted run, filled from the ledger by script |
| `journal/YYYY-WW.md` | Five to ten lines a week |
