# Security

Please do not report security problems in public issues.

Email vijay@vijayjavvadiresearch.ai with a description, the version, and steps to reproduce. You will get an acknowledgement within five days. Fixes are released as patch versions (for example v1.2.1) and credited in the release notes unless you prefer otherwise.

Things that count as security problems here include: any way to make the agent read a credential or send it to a model; any way around the gate or the approval step; a write to a tracker or system of record without a person's approval; and anything that makes a report disagree with its ledger.
