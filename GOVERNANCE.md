# Governance

attestqa is maintained by Vijay Prasad Javvadi. Decisions are recorded in `research/decisions/` as short decision records.

Four rules are not negotiable without evidence:

1. A test may be strengthened; it may not be softened. Rules that refuse weakening are not loosened without a ledger-backed argument that the refusal was wrong.
2. Reports are counted from the ledger, never from the model's account of itself.
3. What the agent must not do, it cannot do: capability removal is preferred to instruction.
4. Every refusal says how it can be cleared by the agent it is shown to.

A pull request that weakens one of these will be closed with an explanation, not merged. A pull request that shows, with runs and events, that a rule refuses something honest is very welcome.
